# 个人主体版本的公开社区收缩

原产品链路保留：首页 → 录音或文字输入 → 后端转写/文本分析 → AI 绘本任务 → 图片生成 → 绘本详情 → 我的书架与历史。原视觉资源、生成参数、Prompt 和数据库结构未改。

关闭公开社区：`miniprogram/app.json` 不注册广场与投稿页；底部导航、书架及个人中心移除可见入口；旧页面和 API 客户端由 `COMMUNITY_ENABLED=false` 拦截。后端 `Settings.COMMUNITY_ENABLED` 默认为 `False`，公开列表、详情、图片、投稿及互动接口返回 404，仍允许作者将旧投稿设为私密或删除。如未来恢复，需在审核类目和主体资质确认后同时开启前后端并恢复路由与入口。已有公开投稿数据不删除。

私人作品使用原有鉴权接口 `/api/v1/diaries`，继续支持生成、查看、编辑和删除。原生好友分享仅分享小程序首页，不包含私人绘本全文；公开作品链接不再进入详情。

上线前仍需核对微信公众平台的账号名称、简介与服务类目。审核截图也将“记录”列为驳回原因，因此关闭社区仅降低社交属性，不能保证个人主体审核通过。2026-09-26 已部署后端社区关闭改动，线上健康接口返回 200、公开分享接口返回 404、未登录私有日记接口返回 401；服务器原文件备份在 `/opt/sites/vonnie.xyz/backups/community-off-20260926-173911`。同日已通过微信开发者工具上传 1.0.2 开发版，回执见 `miniprogram/wechat-upload-1.0.2-community-off-20260926.json`。未提交审核或发布正式版。原完整源码备份保存在 `work/voonie-full-feature-source-before-ugc-offline-2026-09-26.zip`，包含后端 `.env`，按用户要求保持原样。
