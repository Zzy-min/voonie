# 个人主体审核驳回后的本地功能版本

> 此页记录较早的本地插画原型，已被 `community-scope-2026-09-26.md` 的最小改造方案取代；原型源码保留但不进入小程序包。

审核截图指出用户自生成文字、图片、音频的记录和分享属于当前个人主体未开放的“社交-笔记”范围。用户提供的规则第 2.1 节要求实际服务与类目一致，第 3.1.5 节要求具有实际使用价值。

当前小程序仅注册 `pages/local-book/index`。用户可以选择内置插画、在本机录音、将录音与插画组合成条目并在本机播放。新流程不调用后端，不登录，不上传，也不提供公开分享。旧日记、AI 绘本、聊天及社交页面的源码仍在原目录，服务端数据也未删除；它们不在当前小程序路由中。

完整功能源码备份：`work/voonie-full-feature-source-before-ugc-offline-2026-09-26.zip`。备份中的 `miniprogram/app.json` 和 `miniprogram/app.ts` 是下线前配置；其余代码和资源随压缩包保存。该备份保留了 `backend/.env`，按用户选择保持完整，应仅由授权人员访问。

恢复功能时，先在隔离工作区解压备份并比较当前代码，不要直接覆盖后来修改。平台账号的名称、简介及服务类目需与实际功能单独核对；本地保存录音仍可能被认定为“记录”，不能仅凭此版本保证审核通过。微信开发版上传、提审和发布均须分别验证，当前改动没有执行这些平台动作。
