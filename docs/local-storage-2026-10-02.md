## 数据流与失败处理

服务器日记 → 本机账号目录/存储备用通道 → 首屏文字 → 独立图片加载 → 后台同步更新。文件和存储备用通道选择最新快照；两个通道都写入失败时提示本机保存失败，当前界面可继续读取内存副本，但重开后的持久化不保证。

固定保存：保存日记及固定意图 → 下载所有参考图和正文图 → 验证文件及索引 → 显示完成。未完成的固定意图保留，便于单独继续下载；不会宣称已全部离线保存。

注销：先完成服务器注销 → 清理该账号登记的本机副本与文件 → 清除登录会话。若本机文件清除失败，明确提示云端已注销并需要处理本机数据。其他账号和归属不明旧文件保留。
