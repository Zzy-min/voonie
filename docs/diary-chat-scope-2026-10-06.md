# Vonnie 日记交互范围限制

## 范围

用户要求仅允许私人日记相关交互，禁止百科、外部知识和联网问答。审核截图展示“袁隆平是谁”的百科回答，拒绝原因同时提及AI问答、AI换脸视频、AI绘画等个人主体尚未开放服务。本轮处理问答范围，保留现有UI和绘本功能，不据此宣称其他服务类目合规或保证审核通过。

## 实现

- 服务端 `/api/v1/pet/chat` 在读取日记/记忆之前检查请求范围。
- 无私人记录上下文的裸人物/概念提问（例如“袁隆平是谁”）直接返回固定日记引导，不调用生成模型。
- 其他请求使用现有模型分类；仅允许个人经历记录、日记整理/回顾、相关情绪倾听和简短问候。混合外部任务、包装成日记的百科任务及历史越界追问必须拒绝。
- 日记生成回复遵守专用系统边界，再检查回复和引用字段；越界、无明确通过、异常或8秒范围检查超时均返回固定引导。任何回复内容均在检查完成前不发送SSE token；原内容审核保留。
- 固定危机安全支持保留，未将危机消息送入通用问答。记忆授权和账号隔离保持原逻辑。
- 当前模型请求只使用chat/completions，没有搜索/浏览工具；模型联网调用与联网查询资料是不同的行为。即使模型知道百科答案，也受上述检查限制。
- 每个允许的正常AI回复增加两次现有模型的范围检查；会增加调用量和等待时间，未测量真机延迟。未新增服务商或付费审核服务。

## 验证

`test_pet.py`、`test_pet_scope.py`、`test_providers.py` 合计55项通过。包括直接百科拦截、日记包装/混合请求拒绝的控制路径、异常分类、拒绝默认、输出越界、日记人物回顾及JSON/SSE契约。语义分类及输出分类使用控制测试替身，不能作为真实模型在所有对抗输入上均正确的证明。

代码审查发现并修复日记人物回顾误拦、非字符串分类导致异常两项问题；再次审查未发现P1/P2。
