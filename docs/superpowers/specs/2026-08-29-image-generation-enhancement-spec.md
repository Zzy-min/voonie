# 生图能力与漫画分镜深度增强设计规范 (Image Gen & Comic Pipeline Spec)

## 一、 背景与目标

根据对 **LoreVista** 生图管线的深入研究，结合 Voonie 治愈系小狗陪伴与四格日记绘本的产品定位，我们对生图系统进行系统化升级，重点解决以下核心问题：
1. **人物与宠物形象一致性**：解决跨分镜人物或小狗走形的问题，建立「小主人 + 陪伴犬 Voonie」双角色一致性锚点；
2. **专业画风与分镜提示词工程**：吸收日系高质量赛璐珞、治愈水彩与光影渲染词库，提升画面层次与故事张力；
3. **单幕独立重绘交互**：支持在绘本查看器中对单张不满意的分镜进行单独重画与微调，避免整篇 4 幕推倒重来；
4. **生活照片垫图/参考图生成（图生图）**：允许用户在写日记时附带 1 张生活实拍图，生图模型结合照片特征生成绘本。

---

## 二、 架构与模块设计

### 1. 角色一致性锚点与提示词工程 (`prompt_builder.py` / `storyboard_agent.py`)
- **双角色设定卡 (Dual-Character Bible)**：
  - **小主人 (Owner)**：短发眼镜、黄色大卫衣/日常暖色穿搭、清爽治愈少年感；
  - **Voonie 陪伴小狗**：橙白毛色、毛茸茸柯基柴犬混血萌犬、圆溜溜黑曜石大眼、治愈笑容、摇尾巴；
- **风格预设增强 (`STYLE_PRESETS`)**：
  - `anime_cel` (日系高光赛璐珞)：全彩高饱和度、细腻色彩渐变、柔和漫反射边缘光、精细线描与高光；
  - `healing_watercolor` (温暖治愈水彩)：清透水彩晕染、纸质肌理感、温馨低饱和莫兰迪调色；
  - `vintage_picturebook` (复古童话绘本)：手绘木版插画质感、故事绘本构图。

### 2. 单幕独立重绘管道 (`panel_retry` API + UI)
- **后端接口**：`POST /api/v1/diaries/{job_id}/panels/{panel_index}/regenerate`
  - 提取目标分镜的原有描述或用户微调 prompt；
  - 调用 `image_gen_service.generate_panel_image` 单独生成该格图片并更新存储；
  - 自动更新 composite comic 合成条漫并同步 DB 记录；
  - 返回更新后的单格图片 URL 与完整状态。
- **前端交互 (`StoryBook.tsx`)**：
  - 翻页浏览时，右上角提供「🎨 重新绘制这一幕」按钮；
  - 点击后展示微调弹窗或一键重绘，显示独立加载状态，生成完成后实时替换当前页图片。

### 3. 照片垫图/参考图上传 (`DiaryCreator.tsx` + `ArkImageProvider`)
- **前端上传**：
  - 在文字输入框下方提供「📷 添加今日照片（可选）」按钮；
  - 支持上传 JPG/PNG 格式，展示精致缩略图和一键移除按钮；
- **后端传递**：
  - `GenerateComicFromTextRequest` / API 接收可选的 `ref_image_b64`；
  - 后端将其传递给 `ArkImageProvider`，作为火山引擎 Seedream 的参考图 `image: ["data:image/png;base64,..."]` 数组；
  - 提示词中自动注入【视觉参考优先】引导词。

## 三、 验证计划

1. **自动化测试**：
   - 单元测试覆盖提示词构建、双角色一致性卡、单幕重绘路由与错误回滚；
   - 前端 TypeScript 类型检查与 Node 组件测试通过；
2. **真实环境联调**：
   - 使用 DeepSeek LLM 生成 4 幕分镜；
   - 使用火山引擎 Ark 生图模型验证单幕重绘与画质表现；
   - 前端页面完整测试翻页、单幕重绘与照片上传流程。
