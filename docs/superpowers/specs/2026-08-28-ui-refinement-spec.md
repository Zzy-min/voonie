# Voonie UI 精修设计规范

## 1. 设计愿景与情感基调
- **定位**：治愈系小狗漫画语音日记，告别冰冷生硬的 SaaS 卡片墙与工具感；
- **色彩与质感**：奶杏暖桃渐变基调（`#fff8f2` ~ `#f9ead7`）、细腻毛玻璃（Backdrop Blur）、柔和纸质阴影与烫金质感微边框；
- **字体排版**：中文字体选用温润楷体（KaiTi / STKaiti）展示故事正文与每日名言，搭配现代无衬线体显示状态与操作；
- **小狗互动感知**：Voonie 吉祥物具有多种拟态动作（挥手、打瞌睡、眺望、玩耍），在空状态、录音、聊天和绘本翻页中自然陪伴。

## 2. 核心模块精修规划
1. **首页 (Home)**：
   - 每日一句沉浸式画框，伴随睡眠小狗姿态与呼吸感微光；
   - 快速灵感词条（野花散步、热咖啡、放学时光、朋友聚会），支持一键填充或触发说话；
   - 情绪卡片与近期绘本重构，增加微动效与封面悬浮浮动效果。
2. **日记创作流 (DiaryCreator)**：
   - 沉浸式创作卡片，增加常用灵感气泡辅助输入；
   - 录音控制栏层级提升：VU Meter 声波波形律动、红点呼吸提示、结束并识别/取消录音高对比主次分级；
   - 生成状态增加动态情绪解析阶段动画。
3. **绘本阅读器 (StoryBook)**：
   - 仿真绘本翻书质感（装订线、立体书脊阴影、金箔心情印章）；
   - 双页排版优化：左页精美楷体旁白 + 右页全景插画 / 四格漫画；
   - 翻页操作与进度微指示器。
4. **情绪记录 (Mood)** 与 **回忆日历 (Calendar)**：
   - 从纯文本列表升级为情绪趋势图谱、心情占比标签与沉浸式日历回忆流；
   - 支持按心情标签筛选、删除确认对话框与绘本跳转。
5. **个人中心 (Profile)**：
   - 温暖小主人名片排版、云端记忆开关、数据导出与安全销毁流程。
