# Voonie 全站 UI 精修实施方案

## 目标与改动概览
针对 Voonie 全站进行深度 UI 视觉与交互精修，打破通用 SaaS 布局，强化治愈系插画绘本的纸质触感、生动微动效与小狗陪伴感。

## 详细改动

### 1. `voonie/web-v2/app/page.tsx`
- **创作页 (DiaryCreator)**：
  - 增加灵感气泡（“🌸 散步时看到野花”、“☕ 喝到好喝的饮品”、“⛅ 看到了温柔的晚霞”），点击可快速填入灵感；
  - 优化录音控制栏的视觉层次，区分高亮主操作（结束并识别）与辅助操作（取消录音）；
  - 字数与状态提示更加温和细腻。
- **绘本阅读器 (StoryBook)**：
  - 增加书本装饰金线、纸张纹理感背景、左页心情印章（Mood Stamp）与精美页码标识；
  - 丰富翻页指示点，支持悬浮预览和精致翻页微动效。
- **情绪记录页 (Mood)**：
  - 增加情绪分布概览标签（治愈、开心、平静等），以及带有情绪渐变条的情绪卡片；
  - 空状态配图升级为小狗招手插画与暖心文案。
- **回忆日历页 (Calendar)**：
  - 升级为带封面预览、日期标签与阅读操作的回忆流卡片；
  - 增加删除确认弹窗与平滑过渡。
- **个人中心页 (Profile)**：
  - 升级为小主人名片卡片，整合昵称、每日一句便签、云端记忆开关与数据备份管理。
- **陪伴小狗对话弹窗 (Chat Dialog)**：
  - 增加快捷话题气泡（“🐾 讲个温暖的小故事”、“🌟 夸夸我今天”、“🌿 听听我的心事”）；
  - 优化消息气泡与小狗头像动作。

### 2. `voonie/web-v2/app/globals.css`
- 强化纸张触感阴影、暖色微光边框、声波跳动与卡片悬浮升起动效；
- 完善移动端与平板端媒体查询，确保按钮可见性与阅读器自适应。

## 验证方案
- `npm run typecheck`
- `npm run lint`
- `node --test tests/*.test.mjs`
- 浏览器响应式与布局实测。
