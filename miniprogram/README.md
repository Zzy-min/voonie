# Voonie 微信小程序使用与开发指南

> **把平凡日子温柔珍藏 · 治愈系数字手帐与伴随式 AI 宠物**

本项目是 Voonie 的独立微信小程序版本，严格对齐官方 10 页高保真设计模版（`media_1788445639772.jpg`），全量接入 Voonie 后端 API、数据库用户隔离体系与 AI 多模态流水线。

## 🚀 如何在微信开发者工具中打开与预览

1. **启动微信开发者工具**：
   - 选择 **“导入项目”**。
   - 项目目录选择：`C:\Users\Lenovo\OneDrive\文档\邮件\voonie\miniprogram`（或者您将项目移动到的对应路径）。
   - AppID：可填入您自己的小程序 AppID，或者选择 **“测试号”**。
2. **开发环境网络配置**：
   - 默认请求地址为生产环境 `https://vonnie.xyz`。
   - 如需本地联调（`127.0.0.1:8000`），请在微信开发者工具右上角点击 **“详情” ➔ “本地设置” ➔ 勾选 “不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”**。
3. **编译与运行**：
   - 点击 **“编译”**，即可在模拟器中即时查看与体验全部 10 个高保真页面与微动效。

## 🛡️ 核心隐私与安全设计

1. **严格的用户数据隔离**：
   - 小程序端所有请求均携带设备或用户凭证，由服务端根据 `Bearer Token` 确定操作主体，客户端绝不传递 `user_id`，杜绝越权访问。
2. **日记默认私密（Private）**：
   - 在“发布日记”页中，默认设置必须为“仅自己可见”。只有当用户主动选择“公开在分享广场”并二次确认后，作品方可在广场展示。
3. **断网与切后台草稿保护 (Draft)**：
   - 录音中断或生成中断时，未完成文字和录音路径暂存在本地安全缓存 `voonie_diary_draft` 中，下次打开首页会自动提示“检测到未完成草稿，点击继续”。
