# CHANGELOG_UI_ALIGN

日期：2026-09-05
范围：`miniprogram/` 原生微信小程序
目标：按 UI 案例图（`docs/design/voonie-ui-case.jpg`）与需求单 `docs/pi-briefs/2026-09-05-p0-p2-ui-align.md` 从 P0 对齐到 P2。
未改动 `backend/`、`web-v2/`。未提交任何 API Key。

---

## P0

### 1. Tab 文案对齐（首页/日记/萌宠/书架/我的）
- `app.json`：`tabBar.list` 改为 `首页 / 日记 / 萌宠 / 书架 / 我的`；中心 Tab 由「录制」改为「萌宠」，第 4 位由「绘本」改为「书架」。
- `custom-tab-bar/index.wxml`：中心凸起大圆钮文案「录制」→「萌宠」（🐾），图标 🐾 保留；第 4 位「绘本」→「书架」（📚）。
- `custom-tab-bar/index.ts`：`attached()` 读取 `app.globalData.activeTab` 以同步选中态。

### 2. 中心 Tab「萌宠」不再进录音页
- 新建独立萌宠页 `pages/pet/`（全屏聊天，复用 `chatWithPet` API）：
  - 聊天消息列表、输入条 + 麦克风。
  - 快捷 chip：🐾 陪陪我 / 📝 写日记 / 🕯️ 我有愿望。
  - 「写日记」→ `pages/record`（录音）；「我有愿望」→ `pages/share`（发布）；「书架」角标 → `pages/bookshelf`。
- 录音入口收敛：`pages/index` 与 `pet-chat-drawer` 的录音跳转由 `switchTab` 改为 `navigateTo`（`record` 已不再是 Tab 页）。

### 3. 「书架」不再用「绘本」文案
- 新建 `pages/bookshelf/` 书架/绘本架页：展示日记手帐书本陈列（封面/心情/日期），空态引导，以及**分享广场**作为子入口卡片。
- `pages/square` 由 Tab 页降为子页（从书架进入），增加返回按钮；搜索/推荐/最新保留。
- 个人页「我的绘本」快捷与统计改叫「我的书架/书籍」，跳转指向 `pages/bookshelf`。

### 4. 「日记」Tab 信息架构对齐
- `pages/calendar`（日记 Tab）顶部增加「日记回忆」标题 + 「翻翻日记本」引导横幅（`onOpenLatestDiary` → `/pages/diary?id=latest`），让用户感知这是**日记回忆体系**而非莫名日历。

## P1

### 5. 首页底栏改为输入条 + 麦克风
- `pages/index` 底部新增案例式输入条 + 圆形 🎙️ 键；输入内容回车直接投递到发布页 `pages/share?text=…`，点 🎙️ 进录音页。
- 原胶囊 CTA「说说今天发生的事」保留为次要入口。

### 6. 聊天快捷 chip 文案对齐案例
- `components/pet-chat-drawer`（首页浮层）与 `pages/pet` 的 chip 均改为：**陪陪我 / 写日记 / 我有愿望**（原「记一下/陪我聊聊/找找回忆」）。
- 抽屉内新增对应动作 → 录音 / 发布。

### 7. 萌宠能力独立可感
- 新增 `pages/pet` 作为中心 Tab 独立页（不只首页浮层），萌宠可聊天、可引导写日记与愿望。

## P2

### 8. 文案对齐
- 日记页「切换微色」→「**切换版式**」（`pages/diary`）。
- 个人页「时光回忆」→「**时光胶囊**」；「绘本」统计 →「书籍」。

### 9. 登录补齐（至少 UI）
- `pages/auth`：新增**手机号/邮箱**切换（登录方式胶囊）；新增 **Apple 登录**按钮入口（UI 就绪，展示占位提示）；微信登录保留。

### 10. 体验增强（非破坏性）
- `pages/record`：真实音波——新增 `waveAmps` 数组 + `startWave/stopWave` 定时驱动声柱高度（录音时跳动、暂停/停止定格），替代原 CSS 假动画。
- `pages/diary`：翻页动效——翻页时 `turnKey` 触发 3D 翻页展开动画 `.page-turn`。

## 在微信开发者工具中验证
1. 用开发者工具导入 `miniprogram/` 目录，编译运行。
2. Tab 栏：确认底部为 首页/日记/萌宠/书架/我的，中心大圆钮为「萌宠」。
3. ① 首页：应看到底栏「说说今天发生的事…」输入条 + 🎙️ 键；点击 🎙️ 或胶囊 CTA 应进入「我在听」录音页。
4. ② 中央「萌宠」Tab：进入萌宠页，点击 chip「陪陪我」应发出对话并收到小狗回复；「写日记」应跳录音；「我有愿望」应跳发布页。
5. ③ 书架 Tab：进入书架页显示手帐卡片；「分享广场」入口可进入原 Feed（带返回按钮）。
6. ④ 日记 Tab：日历页顶部有「翻翻日记本：像翻开回忆手帐」横幅，点击可进最近日记。
7. ⑤ 录音页：录制时波形声柱应实时跳动（暂停/继续跟随开关）。
8. 日记阅读页：滚动到底部点「下一页/上一页」，正文应有轻微翻页动画；底部按钮文案为「切换版式」。
9. 个人页：统计条第 2 项为「书籍」，快捷卡第 3 项为「时光胶囊」。
10. 登录页：应看到「手机号/邮箱」切换胶囊与 Apple 登录按钮（按钮点击显示占位提示）。
