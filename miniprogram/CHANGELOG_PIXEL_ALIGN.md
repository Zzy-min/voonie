## 本轮改动摘要（逐屏）

### 1. 登录注册 `pages/auth`
- **第三方登录** 由粗糙 emoji 堆（💬 / 裸 字符）改为**精致圆形品牌徽标**：
  - 微信 → 暖绿渐变圆形徽标 + 「微」字；
  - Apple → 深炭圆形徽标 + Apple 符号 ``。
- 增加 `hover-class="social-btn-hover"` 按压微缩反馈；品牌圆角柔和化。
- 顶栏主按钮为大圆角暖橙 `#D9845B`、顶部小狗居中 + 呼吸动画（沿用 `dog_avatar.png` + `anim-breathe`）。

### 2. 互动首页 `pages/index`
- **主交互切换**：案例式**底栏「输入条 + 圆形麦克风」成为主交互**（贴 Tab 上方，间距 `140rpx + safe-area` 已留足）。
- **弱化**：原大胶囊 CTA「说说今天发生的事」降级为**低调柔和小胶囊**「也可按这里语音开启倾诉」（`soft-cta`），不再抢底栏输入条戏份；Paw/书架快捷 chip 微调保持第二入口。

### 3 / 4. 快捷聊天 / 萌宠
- **`custom-tab-bar` 中心凸起「萌宠」大圆钮**由暗棕改为主色系暖橙渐变 `#E4A968→#D9845B`；选中态加深 `#D9845B→#C26741` 并轻微放大（`transform: scale(1.04)`）。
- **Tab 图标/选中态**：选中项主色 `#D9845B` + 轻微上浮 `translateY(-2rpx)`。
- `components/pet-chat-drawer`：标题区改为 **「Voonie · 私人聊天」**（对齐案例屏 3 文案）。
- `pages/pet`：标题区改为 **「Voonie · 私人聊天」+ 副题「记得你的每一件小事 🐾」**，更靠近案例的「私人聊天」定位。

### 5. 语音记录 `pages/record`
- 标题「我在听」+ 副文案、倾听态小狗、波形 + 大号计时、底栏三键（暂停 / 大主钮「结束了」暖橙脉冲 /重录）**保持案例形态**，未回退。

### 6. AI 整理 `pages/generation`
- 标题「正在整理今天...」、步骤清单逐步打勾、暖色进度条、底部伏案小狗 + 说明、「✕ 跳过」右上**保持弱化形态**。

### 7. 翻页日记 `pages/diary`
- **实体感深化**：
  - 纸张背景加入**横向行线 + 双角水彩斑**（`linear-gradient` + `radial-gradient` 纹理），书中环孔、右侧心情书签、翻页动效保留。
  - 日记大标题改**手写感**：`STKaiti/KaiTi` 衬线字体 + 大字距（`letter-spacing: 3rpx`）+ 左侧暖橙竖标装饰条。
- 底部浮动条「上一页 / 编辑 / 切换版式 / 分享」图标+文字悬浮不挡内容，**保持**。

### 8. 回忆日历 `pages/calendar`
- 月历卡片选中日暖橙圆底、有日记爪印点、下方当日回忆双列卡片 —— **保持案例形态**。

### 9. 个人主页 `pages/profile`
- 头像圆 + 编辑角标、陪伴天数、三格统计（日记/书籍/语音天数）、三快捷（我的日记/我的书架/**时光胶囊**）保留。
- 「时光胶囊」图标由 `⏳`（沙漏，词义不符）改为**夹景符号 `🎑`**（更贴「留下时光」意象）。
- 设置列表行高舒适、底部坐书小狗插画 **保持**。

### 10. 分享广场 `pages/square`
- 顶部「推荐 | 最新」切换、Feed 卡（头像+昵称+心情、正文、大图、赞评藏转图标行）保持奶油/轻阴影/圆角大 —— 案例同款。

### 11. 发布日记 `pages/share`
- 顶部「取消 | 发布日记 | 发布」、文本区+字数、插图预览、标签胶囊、可见范围/位置/日期开关、底部工具（照片/话题/心情/位置） —— **保持**案例同构。

## 开发者工具预览检查清单（iPhone 375 / 390 宽）

请在微信开发者工具勾选「iPhone X」375 宽与「iPhone 14」390 宽各过一遍：

1. **登录页**：顶部小狗呼吸动画正常居中；微信/Apple 徽标为精致圆形图标（非 emoji 堆砌）；主按钮大圆角暖橙；底部协议字号偏小居中。
2. **首页**：底栏「输入条 + 圆形麦」贴 Tab 上方、不被 Tab 遮住；原大胶囊已缩小为低调柔和；卡通小狗在房间场景居中呼吸。
3. **萌宠页 / 聊天抽屉**：标题「Voonie · 私人聊天」；chip 为 陪陪我/写日记/我有愿望；用户暖金泡右、纸巾浅底左。
4. **日记**：纸张有纹理行线与水印、环孔在左上、右侧心情书签、大标题有手写感竖标；底条不遮正文。
5. **日历**：选中日暖橙圆底；有日记爪印点；当日回忆双列卡可见。
6. **书架 / 我的**：书脊陈列、坐边小狗插画正常显示；统计/快捷无 emoji 大堆。
7. **生成/录音/发布/广场**：步骤进度、录音三键、发布工具行、Feed 信息流各元素不溢出、主色一致。
8. **全局色板匀称**：背景奶油 `#FAF7F0`、主色 `#D9845B`、无科技蓝/强阴影/Card Wall 残留。

> 蒙点：所有 `src` 均验证存在（`dog_avatar/hero/sidebar/chat_top`、`comic_1`、`user_avatar`），无破图路径引用。

## 验收对照结论

- 首页底栏「输入条 + 采集」成为主交互（原大 CTA 已降级柔和）。
- 首页/日记/书架不再是「开发草稿」形态（纸张纹理 + 手写标题 + tab 暖橙大钮）。
- 微信/Apple 快捷登录为精致圆角图标而非粗糙 emoji（保留 `dog_avatar`/`hero-pet` 官方素材）。
- 色彩、圆角、小狗位置、主 CTA 形态与案例图“一眼同款”。
