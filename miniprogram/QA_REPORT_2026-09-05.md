## 6. 登录与身份系统

### 6.1 邮箱登录 ✅
- 链路：`pages/auth/index.wxml`（input）→ `onSubmit` → `loginUser(email,pwd)`（api.ts:257）→ `POST /api/v1/auth/login` → 后端签发 TokenResponse → `setTokens` 存 access/refresh → `switchTab 首页`
- 校验：邮箱格式（后端 EMAIL_REGEX）、密码 ≥6、loading、重复提交保护（loading 开关）
- 错误展示：后端 `ApiError.message` 透出
- Token：`setTokens` 保存；`request()` 自动注入 `Authorization: Bearer`；401 触发 `refreshSession`
- 重启恢复：`ensureSession()` 已存在 token 则直接复用 ✅

### 6.2 邮箱注册 ✅
- `onSubmit` 未登录态 → `registerUser`（api.ts:276）→ `POST /api/v1/auth/register` → 成功后进首页；重复邮箱 409 处理 ✅

### 6.3 微信登录 ✅（重点核对通过）
- 链路真实为 `wx.login()` → 取得一次性 `code` → `loginWithWeChatCode(code)`（api.ts:266）→ `POST /api/v1/auth/wechat` →后端 code2session → 建/查用户 → 返回 Voonie JWT → `setTokens`
- 前端 `onWeChatFastLogin`（auth/index.ts:71）：先校验协议勾选 → `wx.login` → 调 `/auth/wechat` → 成功进首页；失败展示后端/网络错误
- **明确禁止项已排除**：不再 `POST /auth/device` 冒充微信登录 ✅
- 后端：`auth.py:146` `POST /wechat`，body `{code}`，处理 errcode，session_key 不下发
- 未配置 secret 时后端返回 `503 wechat_not_configured`（fail fast）✅

### 6.4 Apple 登录占位 ✅
- `onAppleLogin` 仅 toast「Apple 登录即将开放」，不走 device/伪造登录 ✅（满足“明确未开放”）

### 6.5 touristappid / WECHAT_MINI 配置 ⚠️
- `project.config.json:5` `appid: "touristappid"` —— 开发/游客号，已在 `CHANGELOG_WECHAT_LOGIN.md` 明确“正式联调需改真实 AppID”
- `project.private.config.json`：不存在（无亮点风险）
- 后端 `WECHAT_MINI_APPID`/`WECHAT_MINI_SECRET` 默认空，`fail fast`；`WECHAT_MINI_SECRET` 未写进任何前端/仓库（后端 changelog 已注明只配 env）
- 风险：**真实联调前置**必须填真实 AppID + 服务器 `.env` 同名密钥；否则微信登录 503。→ 属“联调配置”，不是代码缺陷，非 P0。
